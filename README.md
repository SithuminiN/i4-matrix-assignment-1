# Employee Management REST API

A REST API for managing employees using Node.js, Express.js, TypeScript and MongoDB.

## Technologies

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose

## Features

- Create an employee
- Get all employees
- Get an employee by ID
- Update an employee
- Delete an employee
